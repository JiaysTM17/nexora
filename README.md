## 🌟 1. Giới thiệu Tổng quan (Overview)

**NEXORA** (*ghép từ **Nexus** - Giao điểm kết nối và **Era** - Kỷ nguyên mới*) là hệ sinh thái thương mại điện tử chuyên biệt cho ngành thời trang, giải quyết triệt để bài toán phân mảnh giữa **mua sắm hàng mới (B2C/C2C)**, **thanh lý - tái sinh thời trang tuần hoàn (Trade-In Re-Loved)** và **dịch vụ chăm sóc đồ hiệu cao cấp (VAS Care)**.

Khác biệt với các sàn TMĐT tổng hợp truyền thống, NEXORA tích hợp sâu mạng xã hội phối đồ (**OOTD - Outfit of the Day**), cho phép người dùng biến trải nghiệm phong cách cá nhân thành hành vi mua sắm tức thì thông qua tính năng ghim tag tọa độ sản phẩm trên từng bộ trang phục, mua cả set đồ với **Shop the Look** và kiếm hoa hồng qua **KOC Affiliate Engine**.

### 👗 A. Mạng Xã Hội Thời Trang OOTD (Lookbook & Shop the Look)
- **Coordinate Product Tagging**: Người dùng và KOC ghim trực tiếp tọa độ `(x, y)` của từng món đồ (áo, quần, váy, blazer, phụ kiện) lên ảnh bộ đồ.
- **Shop the Look**: Khách hàng có thể bấm `Mua trọn bộ (Shop the Look)` để tự động thêm toàn bộ các món trong set vào giỏ hàng chỉ với 1 click.
- **Affiliate Attribution Engine**: Phân bổ hoa hồng tiếp thị liên kết (5%) minh bạch theo mô hình Last-Click qua tham số `/?ref=userId`, áp dụng cơ chế tạm giữ 15 ngày để phòng chống hủy đơn/hoàn trả ảo.
- **Chính sách Ảnh Chụp Thực Tế 100%**: Cam kết không sử dụng ảnh AI tổng hợp; mọi sản phẩm đều có hình ảnh chụp thực tế từ các bộ sưu tập đời thực kèm đường link đối chiếu nguồn gốc rõ ràng.

### ♻️ B. Thu Cũ Đổi Mới Thời Trang Tuần Hoàn (Fashion Trade-In Re-Loved)
- **Quy trình thẩm định chất lượng 2 vòng khép kín**:
  - *Vòng 1 (Sơ bộ)*: Người dùng chụp ảnh chi tiết nhãn mác, chất vải, vết sờn; hệ thống phân hạng sơ bộ (Grade S/A/B/C/D) và báo giá ước tính tức thì.
  - *Vòng 2 (Vật lý tại Hub)*: Giám định chuyên viên trực tiếp tại Hub dưới buồng sáng tiêu chuẩn 1000 Lux, kiểm tra tem nhãn, chất lượng vải và khóa kéo.
- **Trade-In Voucher**: Tự động phát hành mã voucher đối ứng tương đương giá trị thẩm định thực tế để khách hàng mua sắm sản phẩm mới trên sàn hoặc thanh lý B2B.

### 🧼 C. Dịch Vụ Giá Trị Gia Tăng Chăm Sóc Đồ Hiệu (VAS Luxury Care)
- **Giao nhận White-glove an toàn**: Túi niêm phong bảo mật chuyên dụng có mã Serial **Zip-seal** một chiều chống can thiệp (tamper-evident).
- **Biên bản kiểm tra quang học 8 góc**: Chụp ảnh macro 8 góc tiêu chuẩn trước khi thực hiện thao tác spa da, giặt khô cao cấp hoặc phục hồi form.
- **Bảo hiểm tài sản 100 Triệu Đồng**: Hạn mức bảo hiểm trách nhiệm bồi hoàn lên đến 100.000.000 VNĐ cho các trang phục, túi xách và giày hiệu xa xỉ.

## 🚀 5. Hướng Dẫn Cài Đặt & Chạy Thử (Quick Start Guide)

### Yêu cầu môi trường
- **Node.js**: Phiên bản `22.x` hoặc `24.x`
- **pnpm**: Phiên bản `>= 9.0.0` (khuyên dùng `11.x`)
- **PostgreSQL**: `15+` (mặc định port `54329`)
- **Redis**: `6+` (mặc định port `63799`)

---

### Phương án A: Khởi động Nhanh 1-Click (Khuyên dùng)

Dự án đã tích hợp sẵn script tự động kiểm tra, thiết lập socket relay và khởi chạy toàn bộ dịch vụ cùng lúc:

```powershell
cd san-quan-ao
powershell -NoProfile -File scripts/start-local.ps1
```

- **Giao diện Web**: [http://localhost:3000](http://localhost:3000)
- **Cổng API Gateway**: [http://localhost:4000/api/v1](http://localhost:4000/api/v1)
- **Tài liệu OpenAPI / Swagger**: [http://localhost:4000/api/docs](http://localhost:4000/api/docs)
- **Kiểm tra trạng thái (Health Check)**: [http://localhost:4000/api/v1/health](http://localhost:4000/api/v1/health)

---

### Phương án B: Cài đặt và Chạy thủ công

1. **Clone repository**:
   ```bash
   git clone https://github.com/JiaysTM17/nexora.git
   cd nexora/san-quan-ao
   ```

2. **Cài đặt dependencies**:
   ```bash
   pnpm install --frozen-lockfile
   ```

3. **Cấu hình môi trường**:
   ```bash
   cp .env.example .env
   cp .env.example packages/database/.env
   ```

4. **Chạy Migration & Seed cơ sở dữ liệu mẫu**:
   ```bash
   pnpm --filter @mac/database migrate
   pnpm --filter @mac/database seed
   ```

5. **Khởi chạy môi trường phát triển**:
   ```bash
   pnpm dev
   ```

## 🚀 9. Kiến Trúc Tách Biệt & Hướng Dẫn Triển Khai Đám Mây (Vercel + Render Deployment)

NEXORA Atelier được thiết kế theo kiến trúc phân lập đám mây hiện đại (**Decoupled Cloud Architecture**), tối ưu hóa hiệu năng, tính mở rộng và khả năng bảo mật bằng cách phân tách độc lập giữa **Lớp Trải Nghiệm Người Dùng (Frontend on Vercel)** và **Lớp Nghiệp Vụ & Dữ Liệu (Backend on Render)**:

```mermaid
flowchart TD
    subgraph VERCEL["Vercel Edge Network (Frontend)"]
        WEB["Next.js 16.4.5 App Router<br/>(SSR, React 19, Lucide Icons)"]
        PROXY["Next.js API Rewrites Proxy<br/>(/api/v1/:path* → Render)"]
    end

    subgraph RENDER["Render Cloud Infrastructure (Backend & Data)"]
        API["NestJS 11 Core API Web Service<br/>(Express, Helmet, Throttler, Swagger)"]
        WORKER["BullMQ Background Worker<br/>(Email, PDF Invoicing, Audit)"]
        PG[("Managed PostgreSQL 16<br/>(Prisma ORM, Row-level Locking)")]
        REDIS[("Managed Redis 7<br/>(Session Cache & Queue Broker)")]
    end

    CLIENT(("Khách Hàng / Nghệ Nhân<br/>(Web & Mobile Browser)")) -->|HTTPS / WSS| WEB
    WEB --> PROXY
    PROXY -->|Zero 3rd-party Cookie Block| API
    CLIENT -.->|Direct Cross-Origin CORS| API
    API <--> PG
    API <--> REDIS
    WORKER <--> PG
    WORKER <--> REDIS
```

### 💎 A. Triển Khai Frontend (Next.js) Lên Vercel

1. **Kết nối Repository**:
   - Truy cập [Vercel Dashboard](https://vercel.com) -> Chọn **Add New Project** -> Chọn Git Repository `nexora`.
2. **Cấu hình Thư mục & Lệnh Build (Root & Build Settings)**:
   - **Root Directory**: Chọn `san-quan-ao` (hoặc `san-quan-ao/apps/web`).
   - **Framework Preset**: `Next.js`.
   - **Build Command**: `pnpm --filter @mac/contracts build && pnpm --filter @mac/web build` (đã được cấu hình tự động trong [vercel.json](file:///d:/A%20-%20Học%20Tập/Thương%20Mại%20Điện%20Tử/san-quan-ao/vercel.json)).
   - **Output Directory**: `apps/web/.next`.
   - **Install Command**: `pnpm install`.
3. **Biến môi trường trên Vercel (Environment Variables)**:
   | Biến môi trường | Giá trị mẫu | Mục đích |
   | :--- | :--- | :--- |
   | `NEXT_PUBLIC_API_URL` | `https://nexora-api.onrender.com/api/v1` | URL công khai của NestJS API trên Render |
   | `API_INTERNAL_URL` | `https://nexora-api.onrender.com` | Kích hoạt Next.js Rewrite Proxy (khuyên dùng để đồng bộ cookie) |
   | `NEXT_TELEMETRY_DISABLED` | `1` | Tối ưu thời gian build |
   | `NODE_ENV` | `production` | Chế độ môi trường sản xuất |

---

### 🏛️ B. Triển Khai Backend & Dữ Liệu Lên Render

#### Cách 1: Tự động 100% bằng Render Blueprint (`render.yaml`) — Khuyên dùng
1. Truy cập [Render Dashboard](https://dashboard.render.com).
2. Chọn **New** -> **Blueprint**.
3. Kết nối Github Repository `nexora`. Render sẽ tự động đọc file [render.yaml](file:///d:/A%20-%20Học%20Tập/Thương%20Mại%20Điện%20Tử/san-quan-ao/render.yaml) và khởi tạo đồng thời:
   - **nexora-api**: Web Service Node.js (Port 10000, Health check `/api/v1/health`).
   - **nexora-worker**: Background Worker cho tác vụ nền BullMQ.
   - **nexora-db**: Managed PostgreSQL Database.
   - **nexora-redis**: Managed Redis Instance.
4. Bấm **Apply** để hệ thống tự động build, migrate schema và kích hoạt dịch vụ.

#### Cách 2: Triển khai Thủ công từng dịch vụ
1. **Tạo Database**: Chọn **New PostgreSQL** -> Đặt tên `nexora-db`, Region: `Singapore`.
2. **Tạo Redis**: Chọn **New Redis** -> Đặt tên `nexora-redis`, Region: `Singapore`.
3. **Tạo Web Service (API)**:
   - Root Directory: `san-quan-ao`
   - Build Command: `pnpm install --frozen-lockfile && pnpm build:api`
   - Start Command: `pnpm start:api`
   - Health Check Path: `/api/v1/health`
   - Environment Variables:
     - `DATABASE_URL`: Lấy từ kết nối Internal Connection String của `nexora-db`.
     - `REDIS_URL`: Lấy từ kết nối `nexora-redis`.
     - `WEB_ORIGIN`: `https://nexora.vercel.app,http://localhost:3000` (cho phép CORS từ Vercel).
     - `COOKIE_SECURE`: `true`
     - `COOKIE_SAMESITE_NONE`: `true`
     - `PORT`: `10000`
     - `HOST`: `0.0.0.0`
     - `SHIPPING_PROVIDER`: `mock`
     - `JWT_SECRET`: Khóa bảo mật ngẫu nhiên 32+ ký tự.
4. **Tạo Background Worker**:
   - Build Command: `pnpm install --frozen-lockfile && pnpm build:worker`
   - Start Command: `pnpm start:worker`

### 🛡️ C. Khởi tạo Schema & Dữ Liệu Mẫu Ban Đầu trên Render

Sau khi Render tạo xong cơ sở dữ liệu PostgreSQL, mở tab **Shell** trong dịch vụ `nexora-api` trên Render Dashboard và chạy:
```bash
# 1. Đẩy lược đồ Prisma lên PostgreSQL
pnpm db:push

# 2. Nạp dữ liệu danh mục, làng nghề & xưởng may độc bản ban đầu
pnpm db:seed
```
